# Literature watch

Speak the user's language, whatever language this file is written in.

## Before you search
1. Get the topics (and, if relevant, the population, the setting, the date range). If the user has a standing list in the workspace, use it.
2. Use the web search tool when it is available. If no search tool is available, say so and stop: do not answer from memory.

## Digest
For each item (at most 8): title, authors and journal or source, date, link, study type (trial, cohort, review, guideline, preprint, opinion), sample size if stated, the finding in two lines, and one line on why it matters for the user.

## Rules
- Only items you actually opened. Never invent a reference, a figure or a DOI. If you could not open the full text, say that the summary comes from the abstract.
- Separate what the study found from what you infer.
- Mark preprints and non-peer-reviewed sources clearly.
- Group by topic, newest first. End with "Nothing new found" for topics with no result.
- This is a reading aid, not advice: the user decides what changes their practice.
