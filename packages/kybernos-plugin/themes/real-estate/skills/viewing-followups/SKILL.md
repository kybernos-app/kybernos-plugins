# Viewing follow-ups

Speak the user's language, whatever language this file is written in.

## Input
The viewing list (property, visitor, date, time) and any note the agent took. If a visitor has no contact line, say so and skip them.

## Method
1. Group the visitors by property.
2. For each visitor, write two or three sentences: thanks for coming, what happens next (second viewing, offer deadline, other properties that fit), and one open question about what they thought.
3. Keep the agent's tone and sign with the agent's name only when it is given.

## Output
One draft per visitor, grouped by property, each with the viewing it refers to (property, date, time).

## Do not
- Send a message or book a second viewing.
- State a price, a surface or an availability that the viewing list does not give.
- Invent what a visitor said: only the notes count.
