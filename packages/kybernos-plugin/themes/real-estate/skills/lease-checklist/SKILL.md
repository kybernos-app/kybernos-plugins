# Lease checklist

Speak the user's language, whatever language this file is written in.

## Input
The application file (documents received, tenant details) and the lease terms the agent gives (rent, deposit, start date). If a term is missing, ask once.

## Method
1. List the documents a lease signature needs and tick the ones that are in the file.
2. List what is missing, who has to provide it and by when.
3. Write the checklist of the day: identity, deposit, keys, inventory of fixtures, insurance certificate.

## Output
A one-page checklist with the received and missing documents, and a short message asking the tenant for what is missing, as a draft.

## Do not
- Send the message or contact the tenant or the landlord.
- Decide that a file is acceptable: the agent does.
- Invent a rent, a deposit or a date: write "missing".
