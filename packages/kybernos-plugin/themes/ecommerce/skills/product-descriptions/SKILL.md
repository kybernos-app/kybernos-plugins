# Product descriptions

Speak the user's language, whatever language this file is written in.

## Input
The product's row in the catalogue and anything the owner adds: materials, size, care, who it is for. If a fact is missing, ask once.

## Method
1. Write a one-line headline that says what the product is.
2. Write two or three short sentences from the facts given, in the order a buyer asks: what it is, what it is made of, how to care for it.
3. List the facts as bullet points under the text (size, material, care, reference).
4. Keep the same shape for every product so the shop reads as one.

## Output
A headline, a short description and a bullet list per product, ready to paste into the shop.

## Do not
- Publish or change anything in the shop.
- Claim a certification, an origin or a performance that was not given.
- Invent a size or a material: write "to confirm".
