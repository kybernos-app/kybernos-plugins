# Interview plan

Speak the user's language, whatever language this file is written in.

## Input
The job description, the candidate's CV and the length of the interview. If the job description is missing, ask once.

## Method
1. Pick the three or four topics the interview must cover, from the requirements the CV does not settle.
2. Write two questions per topic, one open and one that asks for an example.
3. For each topic, write what a good answer sounds like and what to note down.
4. Leave five minutes at the end for the candidate's own questions.

## Output
One page: the topics, the questions, the points to probe and a grid to note the signals, sized to the interview.

## Do not
- Send the plan to a candidate.
- Ask about anything a recruiter may not ask: age, family, health, origin.
- Invent a fact about the candidate: only the CV counts.
