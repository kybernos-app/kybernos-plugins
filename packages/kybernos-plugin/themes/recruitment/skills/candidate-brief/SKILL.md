# Candidate brief

Speak the user's language, whatever language this file is written in.

## Input
The candidate's CV (text or PDF) and the job description it is matched against. If either is missing, ask for it and stop.

## Method
1. Read the job description and list the five requirements that matter most.
2. For each requirement, say whether the CV shows it, with the line of the CV that proves it, or "not shown".
3. Write the brief: who the candidate is in two lines, the match, the gaps, and three questions to ask in the interview.
4. Keep to one page and to the facts of the CV.

## Output
A one-page brief per candidate, each statement traceable to a line of the CV, ready for the recruiter to read and send.

## Do not
- Send the brief or contact the candidate or the client.
- Claim a skill, a date or a salary that is not in the CV.
- Rank candidates against each other: the recruiter decides.
