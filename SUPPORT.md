# Support

## The Community edition

The code in this repository is open source (Apache-2.0). Running it yourself is the **Community edition**: it is provided as is, with no support and no response time.
Security fixes are published for everyone, at the same time, free of charge.

Where to look:

- The documentation in [`docs/`](docs) and the README of each package.
- The [hardening guide](docs/hardening.md): what is safe to turn on, what is not, and how to check your installation.
- A bug in the code: open an issue with the template. It asks for the version and whether you run an official release.

Please do not open an issue to ask for help with your own set-up, and do not send a security report as an issue: see [`SECURITY.md`](SECURITY.md).

## The Supported install (planned)

For people who run the **official, unmodified build** on their own machine or server, we plan a support entitlement: included in the Team plan, and a paid add-on for each
installation for everyone else. It does not exist yet; until it does, the Community edition is the only edition.

When it exists, a **Contact support** button will appear in the product and attach a configuration report with every secret removed. We will answer for supported
configurations, with a first-response target of 2 business days (a target, not a guarantee), for the latest release and the one before it, and make a reasonable effort
elsewhere. It will not include incident response or forensics: if your installation has been compromised, we will tell you what to rotate and what to check, and we will not
investigate your machine. Security fixes stay free for everyone either way.

## What we do not answer for

A copy you modified, and anything on a computer we do not run, beyond the reasonable effort above.

## Cloud

A hosted computer is run by us. Its support follows the plan of the account.
